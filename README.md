# Precious Package — website in progress

Website and brand-kit draft for Evelyn’s Houston-area doula business.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 4178
```

Open http://localhost:4178/ for the website and http://localhost:4178/brand-kit/ for the branding guide.

This is a buildless HTML, CSS, and JavaScript project. Keep the asset folders intact.

## Status

Design and content are work in progress. Booking, availability requests, scheduling, and payments require production integration and verification before launch. Confirm business details, service descriptions, credentials, pricing, and contact information before publishing. Sample artwork and templates are included in the brand kit.
